# Power Platform Solution

This folder is the packaging area for the installable Dynamics 365 managed
solution.

```text
solution/
├── src/        # unpacked solution source generated by pac
├── managed/    # generated managed zips
└── unmanaged/  # generated unmanaged zips
```

The generated zip files are ignored by git and should be published as release
artifacts.

Do not hand-write solution XML unless there is a specific reviewed reason. Use
Power Platform CLI or maker export/unpack flows so component IDs, dependencies,
and environment variables remain valid.
